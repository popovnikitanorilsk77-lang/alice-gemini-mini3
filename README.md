# Алиса + Gemini — приватный навык для Яндекс Станции Мини 3

**Работающая логика (подготовлено локально)**: Yandex Alice webhook -> Google Gemini API -> текстовый ответ, который Алиса читает вслух. Модель по умолчанию — `gemini-3.5-flash-lite` (быстрая, с бесплатным тарифом для подходящих аккаунтов/проектов). Без модификации прошивки и без вмешательства в VPN-сервер.

**Ограничения**: в России Google AI Studio и Gemini API официально недоступны. Для работы нужен доступ к API по правилам Google. У Яндекса жёсткий лимит 4,5 секунды на весь запрос. Не все ответы Gemini успеют за это время. Память контекста — короткая и только в рамках сеанса (стейт Яндекса не больше 1 КБ). На бесплатном тарифе Google может использовать содержимое запросов для улучшения сервисов. Не передавайте голосом конфиденциальную информацию.

## 1. Получить API ключ Gemini

1. Откройте https://aistudio.google.com/api-keys (Google AI Studio) и авторизуйтесь в поддерживаемом регионе/аккаунте.
2. Нажмите **Create API key** (если предлагается выбор проекта — выберите проект с доступным API).
3. Сохраните секретный ключ. **Не вставляйте его в GitHub и не присылайте никому**. Подписка Gemini не требуется для бесплатного API, но бесплатный тариф доступен не всем проектам.

## 2. Создать репозиторий GitHub

1. Откройте https://github.com/new и создайте репозиторий `alice-gemini-mini3` (можно Private).
2. Распакуйте ZIP-архив и загрузите его содержимое в репозиторий через **Add file → Upload files** (не сам ZIP-файл). Сохраните структуру, особенно `api/index.py`.
3. Не загружайте файлы с реальными ключами или паролями. `.env.example` безопасен: в нём только примеры.

## 3. Vercel

1. Откройте https://vercel.com/new -> **Import Git Repository**, выберите созданный репозиторий.
2. В Project Settings / Framework Preset оставьте **Other**. В Root Directory — `/` (корень).
3. До первого Deploy можно добавить переменные окружения (Environment Variables). Если добавляете после — обязательно выполните **Redeploy**.
4. Переменные (Production):

   * `GEMINI_API_KEY` = ключ Gemini из AI Studio
   * `ALICE_WEBHOOK_TOKEN` = случайный секрет длиной 32+ символов (генерируйте в менеджере паролей)
   * `ALICE_SKILL_ID` = ID навыка, из Яндекс Диалогов
   * `GEMINI_MODEL` = `gemini-3.5-flash-lite` (можно не добавлять — уже значение по умолчанию)

5. Нажмите Deploy. При успехе получите домен `https://ВАШ-ПРОЕКТ.vercel.app`.
6. Проверка: откройте **https://ВАШ-ПРОЕКТ.vercel.app/api**. Должен отобразиться JSON `{"status":"ok","service":"alice-gemini"}`. Это **только проверка развёртывания**, не Gemini API.

## 4. Яндекс Диалоги

1. Откройте черновик навыка https://dialogs.yandex.ru/developer/, который вы уже создали.
2. Укажите название «Мой умный собеседник», активационное имя «умный собеседник», пример запроса «Алиса, запусти навык Мой умный собеседник», описание. Дополните обязательные поля и значок по подсказкам консоли.
3. В **Настройки → Тип доступа** установите «Приватный» (сейчас на вашем скриншоте указан «публичный»).
4. Найдите ID навыка — `xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx` — в настройках или URL и внесите в `ALICE_SKILL_ID` в Vercel (после этого Redeploy).
5. В поле **Backend → Webhook URL** укажите

   `https://ВАШ-ПРОЕКТ.vercel.app/api?token=ВАШ_СЕКРЕТ`

   `ВАШ_СЕКРЕТ` — в точности `ALICE_WEBHOOK_TOKEN` из Vercel. **Полную ссылку не публикуйте**, в ней есть секрет.
6. Сохраните, откройте **Тестирование**, проверьте фразой «Привет, кто ты?».
7. Если всё работает — опубликуйте как приватный навык (возможно, понадобится автоматическая модерация).

## 5. Колонка

Скажите: «Алиса, запусти навык Мой умный собеседник». Дальше задайте вопрос. «Сброс» очищает контекст, «Выход» закрывает навык. После выхода работают стандартные музыка и умный дом.

## Если не работает

- **404 по `/api`**: убедитесь, что файлы находятся в правильных папках на GitHub и Vercel импортировал корень проекта.
- **403 от webhook**: проверьте, что в URL тот же `ALICE_WEBHOOK_TOKEN` и в окружении задан соответствующий `ALICE_SKILL_ID`.
- **Ключ Gemini не настроен**: `GEMINI_API_KEY` отсутствует в Production; добавьте и Redeploy.
- **Google отклонил запрос**: у Gemini API может быть недоступен регион, проект, бесплатный тариф или ключ.
- **Gemini не успевает**: сократите вопросы и попробуйте повторно. У Яндекса лимит 4,5 секунды — его нельзя увеличить в настройках навыка.
- **429**: исчерпан доступный лимит Google API.
